# Cybersecurity Portfolio – Nessus & Information Security

## 👤 Role: Information Security Specialist

As an aspiring Information Security Specialist, my focus is on protecting systems and networks by identifying vulnerabilities, analyzing security risks, and applying the necessary controls. This repository showcases my exploration of **Nessus**, a widely used vulnerability scanning tool that aligns with the responsibilities of this role.

---

## 🛠️ Tool: Nessus Vulnerability Scanner

[Nessus](https://www.tenable.com/products/nessus) is a powerful vulnerability assessment tool developed by Tenable. It is used by security professionals to scan for vulnerabilities, misconfigurations, and compliance issues across a variety of systems.

### 🔑 Why Nessus?

- Nessus is an industry-standard tool used by **Information Security Specialists** to conduct internal and external vulnerability assessments.
- It helps organizations identify and prioritize vulnerabilities before they can be exploited by attackers.

---

## 🔍 Features Demonstrated

### 1. **Vulnerability Scanning**
Nessus can scan networks, servers, and devices for thousands of known vulnerabilities. I used Nessus to perform a local network scan and generated a report identifying open ports, outdated software, and security flaws.

### 2. **Custom Scan Policies**
Nessus allows users to create customized scanning policies tailored to specific environments or compliance needs. I configured a policy that excluded non-critical ports and focused on common web server vulnerabilities.
